User Guide

How to load cloud-mask-composite-images, connect EarthRanger and Google Earth Engine, fill in its settings and find the composite it produces.

1. Load the workflow

In the workflow runner, add a new template using this repository's URL, then select cloud-mask-composite-images from the templates list.

2. What you need

  • Access to a Google Earth Engine data source, set up as a connection. The account needs access to the public Sentinel-2 and Landsat collections.
  • Access to an EarthRanger data source, set up as a connection.
  • An EarthRanger spatial feature group outlining the area of interest. Its polygons are merged into one area and the composite is clipped to it; points and lines are ignored. A group whose features are far apart (e.g. every park on a site) gives one very large bounding box, so use a group that covers a single area.

Larger areas take longer. A Sentinel-2 composite of a 100 × 100 km area is about 64 downloads and over a gigabyte before compression. For a first run, try an area of a few tens of kilometres and a range of one to three months.

4. Run it and find the results

Click Submit. The run log shows how many scenes were found, then tile n/N written while the composite downloads. The download is usually the slowest step.

Files are written to the results folder the runner gives the workflow (ECOSCOPE_WORKFLOWS_RESULTS):

FileContents
composite_<sensor>_<roi-hash>_<since>_<until>.tifThe composite. Reflectance and index values are stored × 10 000 as integers. Divide by 10 000 to get reflectance (0–1) or index values (−1 to 1). No data is -32768.
Map .htmlThe interactive map shown on the dashboard.

The dashboard shows the map with the workflow name and time range. The map is a lighter, downsampled preview. Open the GeoTIFF in QGIS or Python for full-resolution values.
